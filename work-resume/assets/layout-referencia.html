Entrada nova (input)Texto novo enviado ao Claude que ainda não estava guardado em cache: suas perguntas e arquivos lidos pela primeira vez. Cobrado a preço cheio de entrada.
Saída (output)Tudo o que o Claude escreveu de volta: respostas, código, comandos e raciocínio. É o tipo mais caro por token (5× o preço da entrada).
Leitura de cacheContexto já guardado (histórico da conversa, instruções, arquivos) que o Claude relê a cada resposta sem reprocessar. Cada token lido custa uma fração do preço da entrada, mas o contexto é relido a cada resposta, então o volume se acumula.
Escrita de cachePrimeira vez que um trecho do contexto é guardado no cache para ser reaproveitado depois. Custa 25% a mais que a entrada normal, mas evita pagar preço cheio de entrada nas respostas seguintes.
Tokens novosEntrada nova + saída + escrita de cache: o trabalho realmente novo da sessão, sem contar o que só foi relido do cache. É a base do indicador de tokens por PF.
Total geralTudo somado, incluindo as leituras de cache. O número fica enorme por causa do cache e não representa trabalho novo.
Custo totalEstimativa em dólares: tokens de cada tipo × preço por milhão do modelo. É valor de tabela da API, não a fatura.

Custo por tipo de token

Como ler esta seção

  • Valor × Exato: o mesmo número; "Valor" é abreviado (k = mil) para leitura rápida e "Exato" mostra a contagem completa.
  • Respostas: quantas vezes o Claude respondeu no período. Cada resposta relê o contexto do cache, por isso a leitura de cache cresce tanto.
  • Custo (US$): estimativa pela tabela de preços da API. Cada tipo de token tem um preço diferente: a leitura de cache é barata por token, mas o volume é tão grande que costuma ser a maior fatia do custo.
  • Por modelo: separa o gasto por modelo do Claude usado (cada um tem preço diferente). Por projeto: separa por pasta de trabalho onde o Claude Code rodou; "~ (fora dos repositórios)" são conversas fora dos repositórios, como ajustes de skill.
  • Custo por tipo de token: mostra para onde foi cada dólar; a % é a fatia do custo total.
  • Tokens novos por PF: tokens novos ÷ pontos de função do período; mede quanto de IA foi gasto por unidade de entrega.
  • Escopo: só as sessões do Claude Code desta máquina; sessões em outro computador não entram. Não atribui tokens a cada card.
